# Friday Master Capability Manifest

Generated from Bhargav's Gemini, Claude, Friday, and Nexus/Jarvis conversation history.

## North Star

Friday is a sovereign, local-first operating intelligence for Bhargav: a Mac-native AI system that listens, understands context, acts through tools, learns continuously, and drives financial sovereignty. It is not a themed chatbot. It is an executor, researcher, builder, operator, and chief-of-staff that lives on the machine.

## Capability Domains

1. **Conversational Presence**
   Terminal, Telegram, and voice chat that feels fast, alive, useful, and context-aware.

2. **Voice System**
   Real-time listening, accurate STT, efficient TTS, interruptible speech, and no duplicate voice loops.

3. **Native Mac Control**
   Accessibility API, AppleScript/JXA, Shortcuts, app/window/process control, and screenshots only as fallback.

4. **System Awareness**
   Running processes, RAM, CPU, heat/load, daemon status, app state, files, and active tasks.

5. **Persistent Memory**
   Mission, history, logs, decisions, active goals, recent dialogue, and project state.

6. **Autonomous Omni-Daemon**
   Background goals, ticks, self-healing, briefings, drift detection, approval queues, and quiet hours.

7. **MCP/Tool Architecture**
   Standard tool boundary for files, browser, GitHub, databases, communications, agency, trading, research, and Mac control.

8. **Multi-Model Orchestration**
   Local models for speed/privacy, cloud models for deep reasoning, task routing, fallback paths, and cost control.

9. **Knowledge Ingestion**
   Repos, awesome lists, docs, APIs, papers, distilled into memory, SOPs, and skills.

10. **Daily Evolution**
    Background learning, repo crawling, open-source model comparison, and knowledge graph updates.

11. **Research And World Awareness**
    News, web, market, AI, and opportunity scanning with cited briefings.

12. **Builder Mode**
    Idea -> validation -> research -> plan -> code -> test -> run -> deploy -> proof.

13. **Agentic Swarm**
    Specialist agents for research, coding, QA, business, trading, content, architecture, and critique.

14. **Financial Sovereignty Engine**
    Friday's central mission: help Bhargav make money first, then become a system that helps others.

15. **Agency Automation**
    Leads, WhatsApp bot demos, outreach, CRM, follow-ups, proposals, invoices, and onboarding.

16. **Trading/Nexus Omega**
    Market data, strategy research, backtesting, paper trading, risk gates, and alerts.

17. **AuditMind/SaaS Engine**
    Compliance workflow modeling, audit automation, demos, and later SaaS build.

18. **Content/AI Studio**
    Faceless channel/content workflows from research to script to voice to video to publishing.

19. **God-Tier UI/HUD**
    Real-time data panels, system state, research visuals, approval queue, and proof of action.

20. **Proof And Anti-Hallucination**
    Every action produces logs/artifacts; Friday must distinguish planned, attempted, and done.

## Core Product Loop

Bhargav asks -> Friday understands the request and mission context -> Friday chooses the right model/tool/agent -> Friday acts on the Mac or business system -> Friday produces proof -> Friday remembers what changed -> Friday suggests or triggers the next useful action.

## Build Priority

1. Reliable terminal + Telegram conversational loop.
2. Memory/session continuity.
3. Native Mac/system awareness.
4. Agency revenue loop: leads -> drafts -> approval -> follow-up -> demo -> invoice.
5. Research/world pulse.
6. Voice streaming and interruptibility.
7. Knowledge ingestion and model orchestration.
8. UI/HUD.
9. Agentic swarm.
10. Trading, SaaS, content studio, and device mesh.
